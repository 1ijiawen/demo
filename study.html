学习目标

掌握 HTML 基础，能够独立搭建结构清晰、语义规范的网页。

通过持续练习，逐步过渡到 CSS 与 JavaScript 的学习。

我的七天 HTML 学习记录

Day 1：HTML 入门

学会创建 HTML 文件、 理解基本文档结构，并使用 Git。

Day 2：基础 HTML 标签

学习标题、段落、列表和超链接， 制作多个互相连接的网页。

Day 3：图片与文件路径

学习 img、alt、相对路径、 图片尺寸与常见图片格式。

Day 4：语义化 HTML

学习 header、nav、main、 section、article 和 footer。

Day 5：HTML 表单

学习 form、input、label、 button、textarea，以及表单验证。

Day 6：网站质量与调试

学习网页导航、基本无障碍、 键盘操作和 Chrome DevTools。

Day 7：最终网站项目

整合之前学过的知识， 完善并测试个人网站。

我的学习成果

  • 能够编写基本 HTML 页面
  • 能够制作多页面导航
