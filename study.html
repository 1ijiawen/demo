学习目标

我希望七天后能自己做出一个结构清楚、在手机上也能正常看的网站。

我把学习分成三步：先学会写，再看懂别人怎么写，最后能说出为什么这样写。

我的七天 HTML 学习记录

Day 1：HTML 入门

学会新建 HTML 文件，认识网页的基本结构， 并第一次用 Git 保存修改。

Day 2：基础 HTML 标签

学习标题、段落、列表和链接， 做了几个可以互相跳转的页面。

Day 3：图片与文件路径

学习怎样把图片放进网页， 也知道了图片路径写错时页面会显示不出来。

Day 4：语义化 HTML

学习用更合适的标签分清页头、导航、正文和页脚， 让代码更容易看懂。

Day 5：HTML 表单

学习制作表单，做了注册页和登录页， 并知道浏览器可以帮忙检查输入。

Day 6：网站质量与调试

练习用键盘操作网页，检查文字和图片是否清楚， 也学习了用浏览器工具找问题。

Day 7：最终网站项目

把前六天的内容合在一起， 检查所有页面，完成了这个网站。

我的学习成果

  • 能独立写出一个简单的 HTML 页面。
  • 能做出五个页面，并用导航把它们连起来。
  • 能给页面加上颜色和排版，让它在手机上也好看。
