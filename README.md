
# 我的 HTML 个人网站

## 项目介绍

这是我在七天 HTML 课程中制作的个人网站。

项目主要用于展示我的个人介绍、
兴趣爱好、网页作品和 HTML 学习记录。

## 项目页面

- index.html：首页
- about.html：关于我
- study.html：学习计划
- register.html：注册表单练习
- login.html：登录表单练习

## 使用的技术

- HTML5
- 少量 JavaScript（仅用于拦截练习表单提交）
- Git
- Chrome DevTools

## 项目目标

1. 建立清晰的语义化 HTML 结构
2. 实现五个页面之间的导航
3. 展示图片、文字和学习记录
4. 制作可操作的表单练习页面
5. 检查键盘操作和基本无障碍功能

## 如何运行

使用浏览器打开 index.html。

这是一个静态 HTML 学习项目，
不包含真实账号注册或登录服务。
