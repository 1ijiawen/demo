
# 我的 HTML 个人网站

## 项目介绍

这是我在七天 HTML 入门课程中完成的个人网站。

网站主要展示个人介绍、兴趣爱好、
网页作品和七天 HTML 学习记录。

通过这个项目，我练习了多页面网站的开发、
语义化 HTML、表单设计、基础无障碍与调试。

## 网站页面

| 文件 | 用途 |
| --- | --- |
| index.html | 网站首页 |
| about.html | 个人介绍与作品展示 |
| study.html | 七天 HTML 学习记录 |
| register.html | 注册表单界面练习 |
| login.html | 登录表单界面练习 |

## 使用的技术

- HTML5
- 少量 JavaScript（用于拦截练习表单提交）
- Git
- Chrome DevTools

## 主要功能

1. 五个主要页面互相导航
2. 展示个人介绍、兴趣爱好和图片
3. 展示七天 HTML 学习记录
4. 提供注册和登录表单界面练习
5. 使用 HTML 原生约束进行基本表单验证
6. 支持基本键盘操作
7. 使用语义化标签组织页面内容

## 项目结构

- index.html：网站首页
- about.html：个人介绍
- study.html：学习记录
- register.html：注册练习
- login.html：登录练习
- images/：网站使用的图片
- BUG_REPORT.md：测试与 Bug 记录

其他 HTML 文件是课程中的独立练习。

## 如何运行

1. 下载或取得项目文件夹。
2. 保持 HTML 文件与 images 文件夹的相对位置。
3. 使用浏览器打开 index.html。
4. 使用页面导航浏览其他页面。

这是静态 HTML 项目，不需要数据库。

## 测试情况

已检查以下项目：

- 页面导航
- HTML 结构与标题层级
- 图片路径和 alt
- 表单基本验证
- 键盘操作
- Chrome DevTools 检查

具体测试记录见 BUG_REPORT.md。

## 已知限制

- 注册与登录仅用于界面练习。
- 不会创建或验证真实账号。
- 不会保存真实用户资料。
- HTML 原生验证不能替代服务器端验证。
- 网站尚未加入完整的 CSS 视觉设计。
